## 1. Origin in the UIDT Lagrangian

The UIDT Lagrangian contains one non-minimal coupling term [A]:

```
L_int = (κ̄/Λ_UIDT) S F^a_μν F^{aμν}
```

Expanding F^a_μν = ∂_μ A^a_ν - ∂_ν A^a_μ + g f^{abc} A^b_μ A^c_ν gives
three contributions to the vertex hierarchy:

```
L_int = (κ̄/Λ) S [∂_μ A^a_ν - ∂_ν A^a_μ]^2
      + 2(κ̄/Λ) g f^{abc} S [∂_μ A^a_ν - ∂_ν A^a_μ] A^{bμ} A^{cν}
      + (κ̄/Λ) g² f^{abe} f^{cde} S A^a_μ A^b_ν A^{cμ} A^{dν}
```

From these three terms one reads off the relevant vertices below.

## 2. The Three-Point Vertex Γ^(3)_SAA

This is the cubic vertex entering the BMW flow of Z_k(v) (see
BMW-truncation-roadmap.md, Step 1).

### Feynman rule (momentum space)

External legs: S(p_1), A^a_μ(p_2), A^b_ν(p_3)  with  p_1+p_2+p_3 = 0

```
Γ^(3),bare_{S(p1) A^a_μ(p2) A^b_ν(p3)}

    = (κ̄/Λ_UIDT) · δ^{ab} · V_{μν}(p_2, p_3)
```

with the tensor structure:

```
V_{μν}(p_2, p_3) = 2 [(p_2 · p_3) η_{μν} - p_{3μ} p_{2ν}]
```

**Symmetry factor:** 2 (from the two identical gauge field insertions)  
**Colour structure:** δ^{ab} (diagonal in adjoint indices)  
**Dimension:** [κ̄/Λ] = -1, [V_{μν}] = +2 → total dim = 1 = [S][A]^2 ✔  
**Evidence tag:** [A] (direct from Axiom 2 Lagrangian, no approximation)

## 3. The Four-Point Vertex Γ^(4)_SSAA (PRIMARY TARGET)

This vertex has NO classical (tree-level) contribution from the
Minimal Lagrangian. It arises from TWO sources:

### 3.1 Source A: Direct double-S differentiation of L_int

The term (κ̄/Λ) S F^2 is linear in S → TWO derivatives with respect to S
vanish at tree level:

```
δ^2 L_int / δS(x) δS(y) = 0  (tree level)
```

**Therefore:** Γ^(4),tree_{SSAA} = 0 from the interaction term alone.

### 3.2 Source B: One-loop contribution (the genuine BMW term)

At one-loop, the vertex Γ^(4)_{SSAA} is generated by a box diagram
with two Γ^(3)_{SAA} insertions connected by two scalar propagators
and two gauge propagators:

```
    S(p1)      S(p2)
      |          |
      ○----------○   <- scalar propagator G_S(q)
     /              \
A^a_μ(p3)        A^b_ν(p4)
      \              /
       ○----------○   <- gauge propagator G_A(q+p3)
```

Explicitly, in the BMW truncation evaluated at zero external momenta
(which is the relevant limit for the flow of Z_k(v)):

```
Γ^(4)_{S(0)S(0)A^a_μ(0)A^b_ν(0)}

  = (κ̄/Λ)² δ^{ab} ∫ d⁴q/(2π)⁴
    × V^{ρσ}(q, -q) [G_S(q)]^2 [G_A(q)]^2
    × V_{μν}(-q, q) · N_c  +  [crossed]
```

where:
- G_S(q) = 1/[Z_k q² + U''_k(v) + R^S_k(q)]  (scalar propagator)
- G_A(q) = 1/[F_k q² + R^A_k(q)]               (transverse gluon propagator)
- N_c = 3  (SU(3) colour factor from adjoint trace)
- [crossed] = crossed box with p_3 ↔ p_4

## 4. Tensor Contraction and Scalar Reduction

For the BMW flow of Z_k(v), only the q²-coefficient of Γ^(4)_{SSAA}
contributes (the rest is absorbed into the potential flow). After
Lorentz projection:

```
V^{ρσ}(q,-q) · V_{μν}(-q,q)
  = 4 [(q·q) η^{ρσ} - q^σ q^ρ] [(q·q) η_{μν} - q_ν q_μ]
```

Contracting with the transverse projector P^T_{μρ}(q) = η_{μρ} - q_μ q_ρ/q²
(appropriate for transverse gluons in Landau gauge):

```
P^T_{μρ} V^{ρσ}(q,-q) V_{σν}(-q,q) P^T_{ν..} 
  = 4 q⁴ · (d-1)²/d   [in d dimensions, d→4]
  →  4 q⁴ · 9/4 = 9 q⁴     [at d=4]
```

This gives the scalar master integral entering ∂_k Z_k(v):

```
[Γ^(4)_{SSAA} contribution to ∂_k Z_k]

  = (κ̄/Λ)² · N_c · 9 · ∫ d⁴q/(2π)⁴ · ∂_k R_k(q)
    × [G_S(q)]^2 [G_A(q)]^2 q⁴
```

**Evidence tag:** [D] (tensor algebra exact; propagator structure BMW-approximated)

```

```

**This is the target equation for the numerical BMW integration.**

For the Litim optimised regulator (D-19):
