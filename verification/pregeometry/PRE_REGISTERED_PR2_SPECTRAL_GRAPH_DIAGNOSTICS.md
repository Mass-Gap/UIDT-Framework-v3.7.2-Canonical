# PR-2 Pre-Registered Spectral Graph Diagnostics

Status: pre-registered software benchmark plan for the separate experimental
pregeometry workspace.

This file registers PR-2 before any implementation or interpretation of
spectral graph diagnostics. It is not a canonical UIDT repository claim and
does not describe canonical release, ledger, or merge status.

## Scope

PR-2 asks whether graph-only diffusion diagnostics computed from the PR-0 toy
carrier and PR-1 null ensembles are deterministic, reproducible, and stable
under predeclared graph transformations.

All physical interpretation remains `[D/E]`. Exact integer invariants remain
`[A]` only for executed software paths. PR-2 spectral graph diagnostics are
`[D]` software diagnostics only.

## Boundary

PR-2 does not introduce physical observables. It does not modify:

- PR-0 growth semantics;
- PR-0 exact invariant definitions;
- PR-1 null-ensemble generation;
- PR-1 separation metrics;
- dashboard read-only semantics.

The term `spectral graph diagnostic` means a registered property of a finite
unweighted graph computation. It is not a physical geometry claim.

## Primary Inputs

PR-2 may consume only:

- PR-0 relational states generated by the existing deterministic toy runner;
- PR-1 null-ensemble graph states or summaries;
- existing exact invariant telemetry: `N(t)`, `E(t)`, `C(t)`, `beta_1(t)`.

No coordinate data, metric position data, external physical target value, or
post-hoc target label may be added as an input.

## Primary Diagnostics

The pre-registered PR-2 diagnostics are:

- graph Laplacian spectrum summary for finite unweighted graphs;
- random-walk return-probability trace over registered walk lengths;
- log-slope diagnostic over predeclared walk-length windows;
- seed-stability summary across registered PR-0/PR-1 runs;
- null-ensemble comparison of the same graph-only diagnostics.

All diagnostics have status `[D]`.

## Required Registration Before Code

Before implementing PR-2 code, the following must be fixed in the run script or
report configuration:

- walk lengths;
- log-slope window bounds;
- graph transformation set;
- null-ensemble sample size;
- seed list;
- failure thresholds for instability and leakage.

These values must not be selected after observing diagnostic outputs.

## Failure Conditions

PR-2 must report a negative or inconclusive result if any of the following
conditions occurs:

- diagnostics are non-deterministic for a fixed seed and configuration;
- output ordering changes under equivalent node relabelling;
- the result is unstable under the predeclared seed list;
- a diagnostic is selected after observing outputs;
- registered forbidden target labels appear in generated dashboard or report
  text;
- artifacts are written outside the allowed pregeometry output paths;
- physical interpretation is upgraded above `[D/E]`.

## Allowed Reporting Language

Allowed:

```text
The executed PR-2 code path computes deterministic spectral graph diagnostics
for the registered finite graph inputs.
```

Allowed:

```text
The PR-2 diagnostic differs from selected null ensembles under the registered
software metric.
```

Not allowed:

```text
The graph diagnostic establishes physical geometry.
```
