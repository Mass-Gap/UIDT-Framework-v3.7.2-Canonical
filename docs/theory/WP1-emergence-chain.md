## Purpose

This document structures the formal mathematical derivation chain that maps the
fundamental vacuum field S(x) (Ontological Level 2/3) to the effective SU(3)
Yang–Mills dynamics (Ontological Level 5). It is the primary working document
for WP-1 of the UIDT research programme.

The central thesis to be formalised:

> *Given Axioms 1–3, the effective dynamics over the S(x) vacuum necessarily
> takes the form of an SU(3) Yang–Mills theory with spectral gap Δ* and
> coupling κ. Yang–Mills is not an axiom but a derived subsystem.*

**What this document does NOT claim:**
- A solution to the Clay Millennium Problem (that requires a global Jaffe–Witten
  construction; see Step 5 and Limitation L9)
- A derivation of γ = 16.339 from first principles (open, L4; see Step 3)
- Closure of the Osterwalder–Schrader axioms (open, Step 5)

**Stratum labelling** (mandatory on every claim):
- [Layer I] Formal QFT statement — falsifiable, Stratum I
- [Layer II] Structural/geometric interpretation — calibrated, Stratum II
- [Layer III] Metaphysical/OSR reflection — speculative, Stratum III

### 2.3 The Gap Equation (Explicit Form)

The gap equation that the fixed point satisfies is the stationarity condition
of the effective potential at the vacuum:

```
V'(S*) = 0
  →  λ_S (S*² − v²) S* = 0
  →  S* = v  (non-trivial solution)
```

The spectral gap Δ* is then determined by the second derivative (mass matrix):

```
V''(S*) = 2 λ_S v²  =  2 × (5/12) × (47.7 MeV)²
        =  2.907 × (47.7 MeV)²  →  Δ* via coupling to gauge sector
```

The coupling to the gauge sector via (κ/Λ) S Tr(FF) lifts the scalar mass
to the GeV scale through the dimensional ratio Λ/v ~ Δ*/v ~ 10⁴.

### 4.1 Wilson Projection: Integrating Out δS

Expand S around the vacuum: S = v + δS, where δS are fluctuations.

With Option B coupling (κ/Λ)S Tr(FF):

```
L_UIDT = −(1/4)F² + (κv/Λ)Tr(FF) + (κ/Λ)δS·Tr(FF)
        + (1/2)(∂δS)² − V(v + δS)
```

Formal integration over δS fluctuations generates:

```
exp(i S_eff[A]) = ∫ Dδs  exp(i ∫ d⁴x L_UIDT[v+δS, A])
```

Leading to an effective gauge action:

```
S_eff[A] = ∫ d⁴x { −(1/4 g_eff²) F² + O(F⁴) + ... }
```

**Proof obligation P1 [Layer I]:**  
Show that g_eff² is finite and expressible in terms of {κ, v, Λ, λ_S}.
This is Open Question **O-P1**.

**Proof obligation P2 [Layer I]:**  
Show that the integration over δS does NOT break the SU(3) gauge symmetry.
This is Open Question **O-P2** — the most critical structural question.

**Known obstruction:** δS couples linearly to Tr(FF) via (κ/Λ)δS·Tr(FF).
This is a gauge-invariant coupling *if and only if* the δS path integral measure
is itself gauge-invariant. This requires verification that the S(x) field
transforms trivially under SU(3) gauge transformations — i.e., S is a gauge singlet.
If S is a gauge singlet (as Axiom 1 implies), then O-P2 is resolved by construction.

### 4.2 Gap Inheritance [Layer I]

The Gap-Inheritance conjecture states:

```
If Δ*[S] ≠ 0  then  ∃ m_gap[A] ≥ f(Δ*, κ, Λ) > 0
```

Three candidate proof paths:

**Path A (direct mass term):**  
The (κv/Λ)Tr(FF) term generates a topological mass for the gauge field.
This is direct if the term acts as an effective mass in the IR.
Requires: showing that the coefficient κv/Λ ~ O(Δ*) — which demands
Λ ~ κv/Δ* ~ (0.5)(47.7 MeV)/(1710 MeV) ~ 0.014, giving Λ ~ 14 MeV.
This appears too small. **Path A requires analytical scrutiny.**

**Path B (spectral argument):**  
The full (S + A) system has a spectral gap Δ*_full ≥ Δ*.
Project onto the gauge sector: show the projected spectrum retains the gap.
Requires: a spectral projection theorem for the coupled (S, A) Hamiltonian.
This is the most rigorous path but needs functional analysis input.

**Path C (scaling argument):**  
Show that no RG trajectory from the UIDT fixed point reaches a massless
gauge-field phase without violating Axiom 3 (contraction condition).
This provides a no-go result: masslessness is forbidden by the fixed point.
This is the most tractable path and should be attempted first.

**Recommended first target:** Path C — formulate as a lemma:
> *Lemma C:* If L(T) < 1 (Axiom 3) and κ > 0, then no RG trajectory
> of the effective gauge coupling g_eff(μ) reaches g_eff → ∞ (confinement
> without gap) or g_eff → 0 (free massless phase) at IR scale μ = Δ*.

### 4.3 Effective Strong Coupling [Layer II]

The mapping from UIDT coupling κ to the effective strong coupling α_s requires
an intermediate step via the renormalised gauge propagator:

```
α_s(μ) ~ g_eff²(μ) / (4π) ~ f(κ, γ, Δ*) / (4π)
```

This is a Stratum II calibration until Path A/B/C is completed.

**Stratum:** I  
**Evidence:** explicitly OPEN — no claim made

### 5.1 What Clay Requires That UIDT Does Not Yet Provide

The Jaffe–Witten formulation of the Yang–Mills mass gap problem requires:

1. **Existence:** A quantum Yang–Mills theory on ℝ⁴ exists as a rigorously defined
   measure on the space of gauge field configurations (OS axioms).
2. **Mass gap:** The Hamiltonian of this theory has a spectral gap above the vacuum.

UIDT currently provides:
- Local constructive evidence for a spectral gap Δ* within the UIDT axiom system [A]
- Lattice-compatible numerical verification at z = 0.37σ [B]
- A derivation programme for the effective SU(3) structure (Steps 1–4, this document)

UIDT does NOT currently provide:
- A globally defined OS measure on all of ℝ⁴
- A proof of uniqueness of the vacuum on the full configuration space
- A Clay-compatible existence theorem

### 5.2 Complementarity, Not Competition

The correct framing [Layer II]:

> Clay asks: *Given SU(3) Yang–Mills, does it have a mass gap?*  
> UIDT asks: *Which vacuum structure forces the emergence of a theory with a mass gap?*

These are different questions. A Clay solution (when found) would establish the gap
*within* SU(3). UIDT attempts to explain *why* SU(3) has this gap by deriving it
from a deeper structure. Both programmes are necessary; neither subsumes the other.
